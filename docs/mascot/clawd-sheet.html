Clawd, one expression per cockpit state

Drawn on Clawd's real 12 x 8 cell grid. He has no mouth, so every feeling comes from the eyes, the arm blocks, the legs and a prop. Each cell is 2 x 2 pixels, which leaves room for arcs and half-lids.
