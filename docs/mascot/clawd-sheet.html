Clawd, thirty states

Drawn on Clawd's real 12 x 8 cell grid (cell = 2 x 2 px), on a 34 x 28 canvas shown at 2x (68 x 56 px). Each card is a mini band: the state, the speech bubble that goes with it, and the button it offers. A red tag appears on any card where a pixel falls outside the canvas; none should.

States

Priority: which state wins when several are true

Fleeting states outrank lasting ones: they play for a few seconds, then the lasting state comes back. Highest first.

  1. Needs you now: raised hand (a permission prompt is open).
  2. Fleeting events (3 to 5 s): oops (a tool failed), bell (turn finished), lab (tests passed), love (handoff saved), idea (plan ready), wizard (draft enhanced), coins (saver routed), unplugged (a connector failed).
  3. While it happens (and 1 s after): dizzy (compacting), then building, reading, browsing (the tool that is running).
  4. Session start (5 s): hello, walk.
  5. Lasting warnings, worst first: asleep (5-hour limit reached), mad (over the daily allowance), on fire (context 80%+), detective (preflight finding), frozen (cache cold), hourglass (cache about to expire), gauge low (allowance within 2%), tipsy (context 50%+), sleepy (5-hour 80%+).
  6. Background: coffee (turn over 2 minutes), typing (turn running), thinking (waiting on the model before any tool), idle (beach).

So a warning never hides a tool you can see working, a finished-turn bell never gets lost behind a warning, and the warning is back as soon as the moment passes. "Reviewed" is in the sheet but has no signal in the plugin API, so it will not ship.
